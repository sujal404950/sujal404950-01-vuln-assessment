# Lab Vulnerability Assessment Toolkit

A Python-based vulnerability assessment tool that automates host discovery,
service enumeration, and known-vulnerability correlation against a target
in an isolated lab network — modeled on the first phase of a real-world
penetration test.

## Why I built this

Most beginner "port scanner" projects stop at printing open ports. This
project goes one step further: it takes the service banners nmap detects
and correlates them against a table of known-vulnerable versions, then
outputs a structured findings report similar to what you'd hand a client
or a manager after a real assessment.

## What it does

1. **Host discovery & port scan** — uses `nmap` (via `python-nmap`) to find
   open TCP ports and running services.
2. **Service/version fingerprinting** — grabs banners for each open port.
3. **Vulnerability correlation** — checks banners against a small local
   table of well-documented CVEs (e.g. the vsftpd 2.3.4 backdoor,
   Samba username map RCE, ProFTPD stack overflow).
4. **Reporting** — outputs both a machine-readable JSON report and a
   human-readable Markdown report with severity ratings and remediation
   advice.

## Setup

```bash
# Install nmap (Linux)
sudo apt install nmap

# Install Python dependency
pip install python-nmap
```

## Usage

```bash
python3 scripts/vuln_scan.py --target 192.168.56.101 --output my_report
```

This produces `my_report.md` and `my_report.json`.

**⚠️ Only scan systems you own or have explicit written authorization to
test.** This project was developed and tested against
[Metasploitable2](https://sourceforge.net/projects/metasploitable/), a
deliberately vulnerable VM built for exactly this purpose, running in an
isolated VirtualBox host-only network.

## Lab setup used for testing

- **Attacker machine:** Kali Linux (VirtualBox VM)
- **Target machine:** Metasploitable2 (VirtualBox VM)
- **Network:** VirtualBox Host-Only Adapter (isolated from the internet
  and home network)

See [`docs/assessment_report.md`](docs/assessment_report.md) for a full
write-up of a sample assessment run against Metasploitable2, formatted
like a professional VA report (scope, methodology, findings, risk
ratings, remediation).
